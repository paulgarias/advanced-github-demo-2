# Code of Conduct

We want this project, and the workshop around it, to be a welcoming and
respectful space for everyone, regardless of background or experience level.

**Expected behavior**

- Be kind, patient and constructive, especially in code review.
- Assume good faith and ask questions before drawing conclusions.
- Credit others' work and give feedback on the code, not the person.

**Unacceptable behavior**

- Harassment, discrimination, personal attacks or derogatory comments.
- Publishing others' private information.
- Any conduct that would be inappropriate in a professional setting.

**Enforcement**

Report concerns to the maintainers listed in
[CODEOWNERS](.github/CODEOWNERS), via a private message or a GitHub security
advisory. Maintainers may edit or remove contributions, and ban contributors,
that violate this code.
